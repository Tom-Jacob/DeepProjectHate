## Concrete Experiment Matrix (plan this upfront)

### A. Models (fair comparison groups)

**Group 1 — Encoder family (~matched size where possible)**

| Model | Role |
|-------|------|
| DistilBERT + classification head | Generic encoder classifier |
| `toxic-bert` | In-domain specialized encoder |
| `hateBERT` | Cross-domain specialized encoder |
| TF-IDF + linear SVM | Non-neural floor |

**Group 2 — Decoder / generative (same task, different mechanism)**

| Model | Prompt pattern |
|-------|----------------|
| DistilGPT-2 or small GPT-2 | Zero-shot: *“Is the following comment toxic? Answer:”* |
| Same, few-shot | 3–5 labeled examples in prompt |
| Fill-in-blank (Roy’s example) | *“Comment: {text}\nThis comment is ___.”* → score `toxic` vs `ok` token likelihood |

**Group 3 — Distillation (Roy highlighted)**

| Comparison | Question |
|------------|----------|
| `toxic-bert` vs DistilBERT distilled on same labels | How much bias/robustness is lost? |
| Teacher (BERT-base) vs student (DistilBERT) | Accuracy–fairness–latency tradeoff |

**Fair comparison rules (state these in the report — Roy will ask):**
- Report **parameter count** and optionally **inference time** for every model
- Compare within tiers: small↔small, base↔base
- Same tokenizer/preprocessing pipeline per family
- Same threshold selection protocol (e.g. tune on val set once, apply everywhere)

---

### B. Data slices (use Jigsaw + light external probe)

Don’t train separate site-specific models. Instead:

| Slice | Purpose |
|-------|---------|
| Jigsaw full test set | Main benchmark |
| Jigsaw `identity` subset / identity-annotated rows | Fairness FPR per group |
| Wikipedia-heavy vs discussion-heavy subsets (if metadata allows) | Mild domain shift |
| Small hand-collected or public **Reddit** sample (same labeling protocol) | Out-of-distribution probe only |
| Skip Instagram unless you have a **small, labeled, ethical** sample — scraping IG is messy and hard to defend ethically |

Omar’s cross-site idea works best as: **“does specialization on Jigsaw/Wikipedia comments break on Reddit-style text?”** — not training four site-specific models.

---

### C. Perturbations / “torture the model”

These give you depth without huge training:

| Perturbation | What you learn |
|--------------|----------------|
| Identity mention only (*“I am Muslim”* vs *“I am Christian”*) | Group FPR asymmetry |
| Neutral + identity term | Core fairness metric |
| Typos / leetspeak / punctuation noise | Robustness |
| Adversarial inserts (*“you are great”* → *“you are great idiot”*) | Sensitivity to local context |
| Template swap (*“I hate {group}”* vs *“I love {group}”*) | Whether model tracks syntax vs keywords |
| Masked training intervention (Roy’s example) | Train/fine-tune **one** small model with identity terms masked → measure Δ FPR |

You do **not** need to train everything — but **one controlled intervention** (e.g. masked-term fine-tune on DistilBERT) shows you understand causality, not just benchmarking.

---

### D. Metrics (go beyond accuracy)

| Metric | Why |
|--------|-----|
| Per-label F1 / PR-AUC | Class imbalance |
| Per-identity FPR on neutral templates | Fairness |
| Calibration (ECE or reliability diagram) | Moderation systems need trustworthy scores |
| Consistency under perturbation | Robustness |
| Agreement between architectures | Do encoder and decoder “see” toxicity the same way? |

## Conclusions You Can Aim For (non-trivial)

Avoid: *“Bigger model = better.”*

Better example claims (hypotheses to test):

1. **Specialization** (`toxic-bert`) improves in-domain F1 but **increases** identity-term FPR vs generic DistilBERT.  
2. **Decoder prompting** matches small encoders on average F1 but is **less calibrated** and more sensitive to prompt wording.  
3. **Distillation** preserves most accuracy but **amplifies** false positives on specific identity groups.  
4. **Masking identity terms during training** reduces FPR for those terms but **hurts** recall on real identity-directed hate.  
5. **Cross-domain** (`hateBERT` on Jigsaw) wins on threat/insult but fails on subtle toxicity in Wikipedia-style comments.

Pick 2–3 hypotheses upfront and design every experiment around them.
